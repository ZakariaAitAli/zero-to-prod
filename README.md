# Zero-to-Prod Platform

Zero-to-Prod helps developers go from an idea to a production-ready deployment on AWS in minutes using Terraform, GitHub Actions, and ArgoCD.

## Features
- Infrastructure as Code (Terraform)
- CI/CD pipelines (GitHub Actions)
- Continuous Deployment (ArgoCD)
- Ready-to-use templates and monitoring

## Structure
- `infra/`: Terraform modules and environment configs
- `ci-cd/`: CI/CD pipelines and ArgoCD apps
- `platform/`: Example applications using the platform
- `docs/`: Usage documentation
